# Agent Rules

Read the current Spec Kit feature specification, plan, and tasks before implementation.

Approved product requirements must not be silently changed.

If implementation reveals a material ambiguity or conflict, stop and report SPEC-CONFLICT.

Do not weaken acceptance tests merely to make implementation pass.

Prefer small, scoped changes and existing repository patterns.

Run relevant tests, lint, typecheck, and build checks before completion.

Implementation must receive independent Claude/GPT review before merge.
